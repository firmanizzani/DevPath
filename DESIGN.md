# DevPath design guardrails

The original pre-redesign interface is the accepted design baseline (Git commit 7e12c82).

- Preserve the original layout, page sections, navigation, cards, and existing copy.
- Keep Geist and JetBrains Mono. Do not replace the font system.
- Keep the original black/grey visual identity and dark theme.
- Improve only specific details, especially text contrast, surface separation, and code readability in light mode.
- Small responsive bug fixes are appropriate; a new hero, visual world, section, illustration, or interactive demo requires a separate request.
- Do not interpret requests to improve the UI as permission for another full redesign.
